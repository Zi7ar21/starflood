# Contributing to Starflood

Starflood is a personal passion project, and as such, I'd like to be able to understand every last bit of code that enters it. Comments, feedback, questions, issues, and pull requests are welcome. All contributions will be licensed under the GNU General Public License Version 3, unless specified otherwise.

## "Assisted" Contributions

COMMENTS, FEEDBACK, QUESTIONS, ISSUES, AND PULL REQUESTS GENERATED BY AUTONOMOUS "AGENTS", "ARTIFICIAL INTELLIGENCE" (AI), "LARGE LANGUAGE MODELS" (LLMs), "SUPER INTELLIGENCE" (SI), ETC. ARE NOT ACCEPTED AND WILL RESULT IN A WARNING FIRST, FOLLOWED BY A PERMANENT BAN.
